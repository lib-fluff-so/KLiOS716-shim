# ios-kl7 v0.5.2 release images

The v0.5.2 source archive was not preserved. These two 16 KiB boot images
are the only surviving artifacts of the release:

- `ios-kl7-v0.5.2-shim_b.img` - normal hardware image (ramoops console log)
- `ios-kl7-v0.5.2-exception-test.img` - deliberate EL1 exception test

`FIX-NOTES-v0.5.2.md` documents the ramoops implementation. The source
snapshot in git is still v0.5.1; the v0.6.0 source archive is the first
snapshot that contains the ramoops code.
